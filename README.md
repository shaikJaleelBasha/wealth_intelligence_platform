# Wealth Intelligence Platform

## 🚀 Frontend URL Structure

---

## 🔐 Auth Routes

| Feature  | URL         |
|----------|-------------|
| Login    | `/login`    |
| Register | `/register` |

---

## 👨‍💼 Admin Routes

> Admin manages stock master & market operations

| Feature               | URL                              |
|----------------------|----------------------------------|
| Admin Dashboard      | `/admin/dashboard`               |
| Add Stock            | `/admin/stocks/add`              |
| Manage Stocks        | `/admin/stocks`                  |
| Update Stock         | `/admin/stocks/edit/:stockId`    |
| Market Prices        | `/admin/market-prices`           |
| Analytics Dashboard  | `/admin/analytics`               |

---

## 👤 Investor Routes

> Investor performs trading operations

| Feature               | URL                               |
|----------------------|-----------------------------------|
| Investor Dashboard   | `/investor/dashboard`             |
| Portfolio List       | `/investor/portfolios`            |
| Create Portfolio     | `/investor/portfolios/create`     |
| Holdings             | `/investor/holdings`              |
| Buy Stock            | `/investor/stocks/buy`            |
| Sell Stock           | `/investor/stocks/sell`           |
| Order History        | `/investor/orders`                |
| Portfolio Analytics  | `/investor/analytics`             |
